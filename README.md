# ThreeJS

A small Three.js experiment from March 2024, built with [DanTCTA](https://github.com/DanTCTA).

A cube you can fly around a textured plane, with a smoothed follow camera.

**Controls:** `W`/`A`/`S`/`D` to move · `Space` up · `C` down

## Run it
Serve the folder with any static server (it uses ES modules), e.g. `npx serve`, and open it in a browser.
